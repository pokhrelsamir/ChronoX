# ⏱️ ChronoX

### Professional Time & Productivity Toolkit

ChronoX is a modern, lightweight, and responsive web-based time utility designed to bring essential time-management tools into one clean interface.

It combines a real-time digital clock, precision stopwatch, countdown timer, and global timezone viewer into a single professional application.

---

## ✨ Overview

Managing time often means switching between multiple tools.

**ChronoX** brings the essentials together.

Whether you need to check the current time, measure an activity, run a countdown, or compare time across different parts of the world, ChronoX provides a focused and intuitive experience without unnecessary complexity.

> **Simple tools. Professional experience.**

---

## 🚀 Features

### 🕐 Live Clock

- Real-time digital clock
- Automatic time updates
- 12-hour and 24-hour formats
- Optional seconds display
- Current date display
- Local timezone information
- Automatic timezone handling

---

### ⏱️ Stopwatch

A precise stopwatch for measuring elapsed time.

- Start / Pause
- Reset
- Lap recording
- Multiple lap support
- Millisecond precision
- Lap history
- Keyboard shortcuts
- Clean elapsed-time display

---

### ⏳ Countdown Timer

A simple and practical countdown system.

- Start / Pause
- Reset
- Preset durations
- Custom countdown support
- Automatic completion detection
- Clear remaining-time display
- Keyboard controls

---

### 🌍 World Time

View the current time across multiple locations.

- Multiple timezone support
- City and country information
- UTC offset display
- Live timezone updates
- Saved timezone preferences
- Add and remove timezone locations
- Automatic daylight-saving handling where applicable

---

### 🎨 Theme System

ChronoX includes a polished theme experience.

- Light mode
- Dark mode
- System theme detection
- Persistent theme preference
- Smooth visual transitions
- Accessible contrast

---

### ⚙️ Preferences

ChronoX remembers important user preferences locally.

Stored preferences include:

- Time format
- Seconds visibility
- Saved timezones
- Theme preference
- Application configuration

No account is required.

---

### ⌨️ Keyboard Shortcuts

ChronoX supports convenient keyboard controls.

| Shortcut | Action |
|----------|--------|
| `Space` | Start / Pause Stopwatch or Timer |
| `R` | Reset Stopwatch or Timer |
| `L` | Record Stopwatch Lap |
| `T` | Toggle Theme |
| `Esc` | Close Settings |

> Keyboard shortcuts are automatically disabled while typing inside form controls.
